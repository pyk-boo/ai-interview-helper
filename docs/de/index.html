Wie findest du Duplikate in einem Array in O(n)?
✦ AI ANSWER
Ich nehme ein Hash-Set: ein Durchlauf, jede Abfrage im Schnitt O(1). 
def find_dups(nums):
    seen, dups = set(), set()
    for n in nums:
        if n in seen: dups.add(n)
        seen.add(n)
    return dups

FAQ

Häufige Fragen

Gibt es einen kostenlosen KI-Interview-Assistenten?

Ja. AI Interview Helper ist ein kostenloser Open-Source-KI-Copilot für Interviews unter Windows und macOS. Es gibt keinen Bezahlplan: Du nutzt einen kostenlosen Schlüssel (Groq, Gemini oder Z.ai) oder ein lokales Modell mit Ollama.

Ist das Open Source?

Ja. Der komplette Quellcode liegt unter MIT-Lizenz auf GitHub: github.com/pyk-boo/ai-interview-helper.

Ist das ein KI-Interviewer?

Nicht ganz. Ein KI-Interviewer stellt dir Fragen. AI Interview Helper steht auf deiner Seite: Er hört die Frage und schlägt eine Antwort vor. Zum Üben eignet sich ein Probeinterview mit Freunden oder einer aufgenommenen Fragenliste.

Ist es eine kostenlose Alternative zu Cluely oder Interview Coder?

Ja. Es deckt denselben Kernablauf ab (Frage hören, Bildschirm lesen, Antwort vorschlagen), ohne Abo und mit dem KI-Modell deiner Wahl.

Funktioniert es für Coding-Interviews auf LeetCode oder HackerRank?

Ja. Drück Strg+Shift+Leertaste, und die Aufgabe auf dem Bildschirm geht an ein Vision-Modell, das funktionierenden Code mit kurzer Erklärung liefert.

Antwortet es auf Deutsch?

Ja. Whisper erkennt Deutsch, und der Assistent antwortet in der Sprache der Frage.

Wo werden meine API-Schlüssel gespeichert?

Nur auf deinem Computer. Anfragen gehen direkt von deinem Rechner zum KI-Anbieter. Es gibt keinen Server dazwischen.
