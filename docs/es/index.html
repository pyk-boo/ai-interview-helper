¿Cómo encontrarías duplicados en un array en O(n)?
✦ AI ANSWER
Usaría un hash set: una sola pasada y cada búsqueda es O(1) de media. 
def find_dups(nums):
    seen, dups = set(), set()
    for n in nums:
        if n in seen: dups.add(n)
        seen.add(n)
    return dups

FAQ

Preguntas frecuentes

¿Existe un asistente de entrevistas con IA gratis?

Sí. AI Interview Helper es un copiloto de entrevistas con IA gratuito y de código abierto para Windows y macOS. No hay plan de pago: usas una clave gratuita (Gemini, Groq o Z.ai) o un modelo local con Ollama.

¿Es de código abierto?

Sí. Todo el código está en GitHub con licencia MIT: github.com/pyk-boo/ai-interview-helper.

¿Es un entrevistador con IA?

No exactamente. Un entrevistador con IA te hace preguntas. AI Interview Helper está de tu lado: escucha la pregunta y te sugiere una respuesta. Para practicar, haz una entrevista simulada con un amigo o una lista de preguntas grabada.

¿Es una alternativa gratuita a Cluely o Interview Coder?

Sí. Cubre el mismo flujo principal (escuchar la pregunta, leer la pantalla, sugerir una respuesta) sin suscripción y con el modelo de IA que prefieras.

¿Sirve para entrevistas técnicas en LeetCode o HackerRank?

Sí. Pulsa Ctrl+Shift+Space y el ejercicio de tu pantalla va a un modelo con visión, que devuelve código funcional con una breve explicación.

¿Responde en español?

Sí. Whisper reconoce el español y el asistente responde en el idioma de la pregunta.

¿Dónde se guardan mis claves de API?

Solo en tu ordenador. Las peticiones van directamente de tu equipo al proveedor de IA. No hay ningún servidor intermedio.
