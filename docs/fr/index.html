Comment trouver les doublons d'un tableau en O(n) ?
✦ AI ANSWER
J'utiliserais un hash set : un seul parcours, et chaque recherche est en O(1) en moyenne. 
def find_dups(nums):
    seen, dups = set(), set()
    for n in nums:
        if n in seen: dups.add(n)
        seen.add(n)
    return dups

FAQ

Questions fréquentes

Existe-t-il un assistant d'entretien IA gratuit ?

Oui. AI Interview Helper est un copilote d'entretien IA gratuit et open source pour Windows et macOS. Il n'y a pas d'offre payante : vous utilisez une clé gratuite (Gemini, Groq ou Z.ai) ou un modèle local avec Ollama.

Est-ce open source ?

Oui. Tout le code est sur GitHub sous licence MIT : github.com/pyk-boo/ai-interview-helper.

Est-ce un recruteur IA ?

Pas vraiment. Un recruteur IA vous pose des questions. AI Interview Helper est de votre côté : il écoute la question et vous suggère une réponse. Pour s'entraîner, faites un entretien blanc avec un ami ou une liste de questions enregistrée.

Est-ce une alternative gratuite à Cluely ou Interview Coder ?

Oui. Il couvre le même fonctionnement de base (écouter la question, lire l'écran, proposer une réponse) sans abonnement et avec le modèle d'IA de votre choix.

Est-ce que ça marche pour les entretiens techniques sur LeetCode ou HackerRank ?

Oui. Appuyez sur Ctrl+Maj+Espace : l'exercice à l'écran part vers un modèle de vision, qui renvoie du code fonctionnel avec une courte explication.

Répond-il en français ?

Oui. Whisper reconnaît le français et l'assistant répond dans la langue de la question.

Où sont stockées mes clés d'API ?

Uniquement sur votre ordinateur. Les requêtes partent directement de votre machine vers le fournisseur d'IA. Aucun serveur intermédiaire.
