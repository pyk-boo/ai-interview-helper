Como você encontraria duplicados em um array em O(n)?
✦ AI ANSWER
Eu usaria um hash set: uma única passada, e cada busca é O(1) em média. 
def find_dups(nums):
    seen, dups = set(), set()
    for n in nums:
        if n in seen: dups.add(n)
        seen.add(n)
    return dups

FAQ

Perguntas frequentes

Existe um assistente de entrevista com IA grátis?

Sim. O AI Interview Helper é um copiloto de entrevista com IA gratuito e de código aberto para Windows e macOS. Não há plano pago: você usa uma chave gratuita (Groq, Gemini ou Z.ai) ou um modelo local com Ollama.

É de código aberto?

Sim. Todo o código está no GitHub sob licença MIT: github.com/pyk-boo/ai-interview-helper.

É um entrevistador de IA?

Não exatamente. Um entrevistador de IA faz perguntas para você. O AI Interview Helper fica do seu lado: ouve a pergunta e sugere uma resposta. Para treinar, faça uma entrevista simulada com um amigo ou com uma lista de perguntas gravada.

É uma alternativa gratuita ao Cluely ou ao Interview Coder?

Sim. Ele cobre o mesmo fluxo principal (ouvir a pergunta, ler a tela, sugerir uma resposta) sem assinatura e com o modelo de IA que você quiser.

Funciona para entrevistas técnicas no LeetCode ou HackerRank?

Sim. Aperte Ctrl+Shift+Space e o desafio na sua tela vai para um modelo com visão, que devolve código funcionando com uma explicação curta.

Responde em português?

Sim. O Whisper reconhece português e o assistente responde no idioma da pergunta.

Onde ficam minhas chaves de API?

Só no seu computador. As requisições vão direto da sua máquina para o provedor de IA. Não existe servidor no meio.
